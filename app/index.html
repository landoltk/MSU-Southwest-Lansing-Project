App Tutorial

Initial App Overview

When the app loads, you will see an overview of Lansing displayed through green block groups. By default, the Southwest Lansing region is already selected and highlighted in blue, indicating that these block groups are active. You can press the "Southwest Lansing" button in the "Choose your data display method:" section to reselect all 22 block groups.

Current Working Features

Filters

Working:

  • Food: Displays community gardens in the immediate area
  • Population: Displays population data after submission
  • Income: Displays median household income per block group
  • Race: Displays amount of people per race in selected block groups.
  • Household Size: Displays average people per household in owned and rented properties

In Progress:

  • Health

Data Viewing Methods

Working:

  • Southwest Lansing: Automatically selects all Southwest Lansing block groups
  • Radius selection: Select a radius in miles and click on the map, intersecting block groups will be selected.
  • Neighborhood-based selection: All Southwest Lansing neighborhood zones are outlined in white, select a white block group and any associated block groups with that neighborhood will be selected.

In Progress:

  • None

Layer 1: Block Groups

  • Green: Not selected, excluded from data
  • Blue: Fully selected, included in data
  • Bright Yellow: Deselected and removed from selection
  • Dim Yellow: Selected and highlighted in displayed data

Layer 2: Block Level

  • Orange: Upon submission, users will be granted the access to change their selected area to a finer level of block level data. They can remove unwanted areas to achieve a more particular selection.

Drawer Descriptions

Filters:
No data can be displayed without selecting a filter. Filters are checkboxes, but only one can be active at a time. The selected filter appears under "Selected Filter:" in the main panel.

About the Team:
This section highlights the Southwest Lansing Project team and recognizes the Center for Community and Economic Development (CCED). It includes roles, majors, and contact information.

How to View Data

  1. Select block groups (or use the default selection)
  2. Click "Submit Selection"
  3. Open the Filters drawer
  4. Select a filter
  5. Click "Show Data"

A data table will appear below the button. You can close it anytime using the "X" in the top right. The table stays until closed or replaced.

Data Tools & Features

Unselect All / Edit Selection:
Unselect All clears all selected groups. After submission, this becomes Edit Selection, allowing you to modify your selection.

Block Group Hyperlinks:
Displays selected groups only. Clicking highlights them in dim yellow without changing selection.

Zoom Controls:
+ zooms in, – zooms out, and the compass allows rotation when clicked and dragged.
